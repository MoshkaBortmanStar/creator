---
description: "OpenSpec: создать изменение из промпта (proposal + BDD-спека + tasks) через движок openspec"
---

Пользователь просит новое изменение: «$ARGUMENTS».

Выполни по шагам (стиль openspec-driver скилла):

1. Если запрос короткий/двусмысленный — задай 1–3 уточняющих вопроса и дождись ответов.
2. Запусти: `./openspec.py --new "$ARGUMENTS"`
   (если specs/MAIN.md нет — сначала предложи `--main`).
3. Прочитай созданный `specs/<change-id>/spec-bdd.md` и выведи пользователю
   компактное резюме: список сценариев S1..Sn одной строкой каждый + краевые случаи.
4. Спроси: править спеку, перегенерировать (--spec/--tasks) или перейти к кодогенерации.

Не выводи содержимое файлов целиком. Не пиши артефакты вручную.
