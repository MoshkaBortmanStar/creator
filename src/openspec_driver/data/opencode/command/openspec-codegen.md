---
description: "OpenSpec: кодогенерация по спеке и таскам изменения (dry-run ревью -> запись)"
---

Пользователь запрашивает кодогенерацию для изменения: «$ARGUMENTS»
(аргумент — ID изменения: полный, префикс или номер).

Выполни по шагам:

1. `./openspec.py --list` — если ID не указан, покажи список
   изменений и попроси выбрать.
2. `./openspec.py --codegen --change <ID> --dry-run`
3. Покажи пользователю список файлов из вывода dry-run, спроси подтверждение.
4. После «да»: `./openspec.py --codegen --change <ID> --yes`
5. Прогони тесты проекта (mvn test или аналог по стеку из .agent/config.yaml).
   Падения дожимай сам в TDD-стиле, ориентируясь на сценарии из spec-bdd.md.
